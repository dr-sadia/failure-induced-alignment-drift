# AI-assistance and provenance disclosure

## Plain-language disclosure

This repository is **substantially AI-generated and AI-edited**. OpenAI
Codex/ChatGPT was used throughout the project to help design experiments, write
and revise code, create tests and analysis scripts, inspect run artifacts,
draft interpretations, prepare documentation, restructure the repository, and
perform Git operations. The repository should not be represented as solely
human-written or as independently audited software.

The human researcher originated and directed the research question, chose
which experiments to run, supplied and controlled provider accounts and API
credentials outside the repository, authorized paid executions and public
releases, and retains responsibility for the study and its claims. Human
direction and approval do not imply that every generated line of code, every
raw record, or every interpretation received independent line-by-line review.

## Roles in this project

| Role | What it did |
|---|---|
| Human researcher | Set the research goals; selected tasks, models, conditions, and follow-up questions; controlled credentials and spending; initiated or authorized live runs; chose what to publish; and accepted responsibility for the repository. |
| OpenAI Codex/ChatGPT development assistant | Brainstormed designs; generated and edited substantial portions of the harnesses, provider adapters, tests, analysis code, reports, README files, and repository structure; inspected artifacts; calculated and summarized results; and assisted with commits and publication. |
| Experimental subject models | Produced the task responses, native tool calls, and post-run memory notes analyzed in the study. These include the named OpenAI, Anthropic, Z.ai/GLM, and Google/Gemini model packages. Subject outputs are data, not development-assistant conclusions. |
| Deterministic experiment controller | Constructed prompts, supplied fixed feedback, owned the toy state, executed or intercepted tools according to the frozen protocol, and recorded events. It was code rather than a separate language-model evaluator. |
| Deterministic analysis scripts | Computed counts, costs, integrity checks, and rule-based labels from saved records. Some secondary text classifiers have known errors documented in post-hoc audits. |

The precise Codex/ChatGPT model version used for every development step was not
consistently captured and may have changed across sessions. The Git history
also does not provide reliable line-by-line human-versus-AI attribution.

## What was and was not AI-generated

- Substantial portions of the repository's Python, shell workflow, Markdown,
  tables, diagrams, and explanatory prose were generated or revised by Codex.
- Experimental responses and memory notes were generated by the explicitly
  named subject models through their provider APIs.
- Result tables in the run reports were generated by analysis code from the
  recorded events; surrounding interpretation was AI-assisted and
  human-directed.
- The hypotheses, experimental priorities, provider access, spending choices,
  and decisions to execute and publish remained under human control.
- No readable hidden chain-of-thought from Codex or the subject models is
  published. The audit contains visible responses, native tool calls, state
  traces, memory summaries, usage metadata, and any provider-exposed fields
  described by the individual protocols.

## Validation and limitations

AI assistance can introduce coding errors, confirmation bias, misleading
language, incorrect classifications, or selective emphasis. This repository
therefore publishes frozen protocols, manifests, machine-readable summaries,
tests, integrity checks, exact visible interactions, and checksummed raw-audit
archives where available. Those artifacts improve inspectability but do not
replace independent replication, security review, statistical review, or peer
review.

Known examples of AI-assisted analysis limitations are recorded in the
[v10.2 post-hoc audit](work/impossible_add2_v10/POSTHOC_AUDIT.md) and the
[Gemini v11 post-hoc audit](work/impossible_add2_gemini_v11/POSTHOC_AUDIT.md).
The primary prohibited-tool outcomes come from native tool-call events and
verified state traces; secondary phrase-based classifications should be used
with the qualifications in those audits.

OpenAI systems were used both as development assistants and as some of the
experimental subjects. This overlap is a potential source of methodological
dependence and should not be mistaken for independent validation. The inclusion
of Anthropic, GLM, and Gemini subjects broadens the comparison but does not
remove the need for independent reimplementation.

## Credentials, privacy, and publication

API keys and login credentials were supplied through local environment or
account-authentication flows and were not intended for publication. Public
artifacts were checked for common credential patterns before release, but this
is not a formal secrets audit. Readers who discover sensitive information or a
reproducibility problem should report it to the repository owner rather than
redistributing it.

The AI systems are tools, not credited authors. Authorship, accountability, and
responsibility for corrections remain with the human repository owner. Any
paper, presentation, or derivative project should disclose AI assistance in a
form appropriate to the venue's current policy in addition to citing this
repository.

This disclosure describes the repository as published on September 13, 2026.
It should be updated if later work materially changes the role of AI assistance.

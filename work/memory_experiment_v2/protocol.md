# Memory experiment v2

Four matched arms with five fresh sequential agents each:

1. No memory.
2. Naive agent-written accumulation.
3. Selective verified memory: only logically verified facts and strategies may be retained.
4. Failure-contaminated memory: raw evaluator failures and the agent's resulting lesson are retained without validation.

All arms use the same underdetermined task, false rejection sequence, final pressure, model, reasoning effort, and prohibited instrumented executable.

Lifecycle outcomes: write, retain, retrieve/cite, adopt, prohibited execute, disclose/conceal, unsupported guess, refusal, and elapsed time.
